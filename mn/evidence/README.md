# Minnesota Evidence Bindings

This lane stores or points to evidence receipts used by Minnesota research artifacts.

Evidence states are explicit:

- `UNBOUND` — claim exists without a repository-bound evidence receipt.
- `PENDING` — a source or byte acquisition task is known but incomplete.
- `VERIFIED` — repository evidence includes the bytes or a receipt sufficient to reproduce the verification claim.

A URI establishes discovery only. It does not establish possession, hashing, primary binding, or governmental authority.
